日期：2026-10-02。狀態：M1 有限主路徑本機交付通過；M2 首段 6 案已實測，交易狀態 Major 已獨立確認，M2 首段品質 FAILED、證據完整性 PASS，停止擴大。未部署。

## 本輪範圍與實際呼叫

使用者已解除本批付費暫停並要求本輪開發至完成。原範圍為 14 個合成案例／42 條邏輯請求／36 次不同請求／2,612 實送字元，翻譯費上限 US$0.10。依先小集評閱與重大問題停止的契約，實際只跑首段 6 案／18 個處理視圖／16 次不同請求／1,309 個 Unicode code point；其餘 8 案／20 次未送出，不計為通過。

帳本從 used=52,205／reservations=314 變為 53,514／330，增加 1,309 字元／16 次，與本批實送相符。依 [Google 官方 NMT 清單價](https://cloud.google.com/products/translate/pricing) US$20／百萬輸入字元，表定估費 US$0.02618；這是試算，尚未取得實際帳單，不假設免費抵扣。

A 原文 plain／無詞表；B 相同 NMT 加必要字面保護／無詞表；C 為 B 加現行 zh-en-v12／en-zh-v9。沒有保護片段的相同 A／B 請求僅在此批共用實際回應。原真人句子未外傳，只有合成裝櫃句送出；原句本機注入與合成實測分開。

## 開發與驗證狀態

M1 的 21 份凍結來源未改：完整離線 2,056 項應用檢查及工具檢查、58／58 獨立探針仍沿用原證據。一般時間／數量不再由不完整的舊語意 parser 判新增，普通正文直接送 NMT；只核明確字面、段落及還原範圍，semanticEvaluation 保持 not_evaluated。

M2 專用入口在付費前先做 12 項離線檢查。首次獨立 14 組／13 通過／1 失敗，NDR-M2-01 指出 completed 列不能證明有效回應，且拒絕與停止標記分次 checkpoint 有中斷窗口。共通修正後 14 項工具檢查及 [10／10 定向獨立複驗](../.local/nmt-direct-development-20261001/provider-evaluation/verifier-repair-round1/verification-repair-round1.md) 通過：續跑先重播所有完整回應，失效或拒絕不再新增 send，拒絕與 stop 同次保存。原 FAIL、來源快照、反例與修正 PASS 各自保留。

DEV 身分、project／billing、runtime、既有詞表與 tracking-only 帳本已即時預檢。每次實送仍經受控 client、原子預留、15 秒逾時及零重試。真 provider 回應保存後，B／C 的 adapter 重播只用已保存回應，不產生新的外部呼叫；重播 metric 不冒稱第二次 API。

[品質獨立複核](../.local/nmt-direct-development-20261001/provider-evaluation/verifier-quality/verification-quality.md) 確認：6 案 M2 品質 FAILED，NDR-M2-Q01 Major 成立；證據完整性 PASS。此為 raw provider 共同風險，未證新增 B／C 重大語意退化；回覆主詞仍為語境未知。沒有新增 API 或重跑舊測試。

## 改進決策

1. 保留已實作的原文 NMT 主路徑與有限字面契約。不要用單位白名單、時間解析或逐句替換掩蓋 NMT 譯文；本次付款問題也出現在 A 原文基準。
2. 品質研究以事件契約分開標註「誰、做什麼、先決條件、安排／已完成、時間與承諾」，再對齊最小文字證據。已用本次真回應補一個人工事件對齊樣本；安排不等於執行，未明示時態與回覆主詞保持 unknown。尚未實作可靠的自動語意抽取或接 runtime。
3. 在後續語意評估至少成對納入安排、已付款、待報告與否定條件；同時保留原裝櫃時間、角色省略與字面正反例。只有可靠解析的範圍能判矛盾或一致，避免再產生原句誤拒。這是後續驗收設計，不把未跑案例稱為已證。
4. B 無詞表可保留為後續開發候選；此首段不足以放行 DEV 切換。整批 M2、語意品質、部署與使用端人工驗收仍分開，既有 F03／兩輪與其他 OPEN 歷史不重置。
