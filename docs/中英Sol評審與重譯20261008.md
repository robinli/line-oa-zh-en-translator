## 執行契約

中翻英、英翻繁中、中英雙向的文字與可得語音逐字稿：原文 → 必要原樣保護 → 一次 general/nmt → 片段／段落核對 → Sol 評審。OK 採用 NMT；NOT_GOOD 或 UNCERTAIN 從原文重譯一次。NMT 已有非空輸出但片段／段落核對拒絕也可重譯；輸入錯誤、NMT API 失敗、無效回應格式不作救援。重譯沿用同一 manifest／carrier／codec 的格式、4500 UTF-16 長度、片段次數／段落與原生提及來源位置檢查，通過才回覆 LINE；不作第二次評審。模型或重譯檢查失敗回覆 🚧。

Sol 固定 gpt-6.1-sol、Responses API、低推理、Standard（service_tier=default）、store:false、max_output_tokens=4096；不提供 tools、previous_response_id 或會話記憶，不自動重試。評審 strict JSON 是 verdict／reason（最多100字），重譯 strict JSON 是 translation。模型結果須 completed、相符模型、唯一 assistant output_text、無 refusal／incomplete／tool call，並核對 usage。定向驗證不能證明所有語意都正確。

評審只接原文、已還原 NMT 譯文、方向及引用；重譯只接原文、保護 carrier、方向及引用，沒有 NMT 譯文／評審理由。原文與引用是待翻譯資料，提示明確拒絕執行其中指示。不傳 LINE userId、groupId、messageId 或別名身分映射；原文自行寫出的人名及 @ 顯示文字仍是待譯文本。

## 引用與時間

只查 lineTranslationMessages 中同 groupId、指定 quotedMessageId 對應 messageId 的已保存原文，limit(2)；恰一筆且非空、最多2000 UTF-16 字元才 known。缺失、重複、超限、失敗或逾時為 unknown；未引用為 not_quoted。不截斷、不追溯其他引用、不拉 LINE 歷史，也不把引用中的額外事實加入譯文。關閉本群記錄保留歷史，仍可按這個受限條件讀取。

TranslationContext 新增 quoteContext、deadlineAtMs，既有保護範圍與 Translator 介面沿用。同一 webhook 從實際收到起50秒，包含批次排隊、品質採集、設定、引用、語音前置及翻譯；最後10秒留給保存與回覆。每次 NMT／Sol 最多15秒且不超過剩餘處理時間。引用／階段控制寫入最長2秒；claim 與所有事件控制寫入亦按50秒絕對期限界限，憑證取得後及實際網路送出前重新核對，不在背景續送；語音下載／STT 在評審流程受相同期限約束。DeadlineScope 統一 operation admission、bounded wait、取消與撤銷；catch／finally、失敗保存、品質操作、全部設定及無 session 回覆也不能延長期限。Firestore 每次 RPC／交易續行核對，scoped 單次 attempt、payload snapshot；已 admission 的 RPC 不可撤回，逾時結果保持未知。評審開關開啟時，中越維持原引擎與內容規則，但同批等待共用50秒；只有中英使用40秒處理界線。LINE／Speech scoped REST transport 可取消，晚取得串流立即關閉。外部送出結果未知時不重送。LINE reply token 儘早使用，超過一分鐘不保證有效。

## 持久控制與資料

沿用各環境事件 claim／NMT provider fence。review、rewrite 各自開始前以 owner fence 交易保存 started；已 started、結果未知、事件重送均不再呼叫。寫入 acknowledgement 遺失不能以後續完成紀錄重置 started。模型生成與 LINE 發送不能在 Firestore transaction callback 內執行。

operation.telemetry.solReview 與品質 completion.solReview 分開記 NMT 檢查／細碼、review／rewrite 狀態與耗時、判定／理由、引用狀態、finalSource 及各自 input／cached／output／reasoning token；reasoning 包含於 output，不再加總計費。finalSource=gpt 的 semanticEvaluation 必須 not_evaluated，不能稱重譯已語意評審通過。NMT 原始 contents/output 延用現行採集；被拒 GPT 原始內容不保存、不打印。舊資料缺欄位保持未知，不回填。品質匯出新增獨立 Sol 彙總，不把 NMT 字面通過或 LINE 成功當語意證明。
