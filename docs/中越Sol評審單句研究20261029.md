# 中越 Sol 評審與重譯單句研究

最後更新：2026-10-29。

使用者要求中越比照現行中英自動評審流程，先測指定一句再評估後續；專用術語日後陸續加入。本輪當時僅為本機研究，中越維持原NMT。後續使用者指定mít color原樣規則並明確授權整合及DEV／PRD發布，最新生效狀態見[中越Sol整合與發布](中越Sol評審與DEV發布20261029.md)；本頁研究失敗與限制不改寫。

## 方法與結果

沿用既有中越 NMT adapter 取得新回應，再以現行 Sol Responses client 評審。提示只把中英語言識別改中越，沒有加入圖片、術語或個案語意提示。OK 採 NMT；NOT_GOOD／UNCERTAIN 由原文重譯一次，重譯作字面檢查，不作第二次評審，對照契約見 [中英 Sol 流程](中英Sol評審與重譯20261008.md)。

2026-10-29 18:15（台北）真實試驗完成：NMT 重現重量對象錯誤，Sol 判 NOT_GOOD，指出貨物重量被譯成包裝重量，並觸發單次重譯。重譯後重量對象改善，數值、日期及兩段結構保留；材料標籤仍採錯誤詞義，未得到使用者附圖支持的品項。

結論是**部分改善，指定句的完整翻譯仍未正確**。不能據單句宣稱中越評審整合或語意品質通過。原文、完整回應及客戶內容只保存於 Git 忽略的私密證據。

## 用量、依賴及邊界

- 使用既有 DEV line-auto-translate-bot-dev、NMT、Firestore 帳本、原隔離 Google 身分及 OpenAI 憑證；預檢核對既有 API、身分／帳務／runtime、帳本政策與模型可用。沒有新增服務、啟用 API、Secret 或 IAM 變更。
- 1 次 NMT，實送 contents 合計 136 Unicode 碼點，共用 nmt-r1.json；來源行分隔不在分段 contents 內，與原文字數不同。上限 10,000 碼點，失敗預留保留。
- 2 次 Sol 生成，固定 gpt-6.1-sol／low／default／store:false／4096 output tokens／零自動重試。保守預留 US$0.110895，已知 token 用量估算 US$0.004272，並非帳單；本次上限 2 生成／US$0.20，已停止新增呼叫。
- 這是本次新授權的單句研究；2026-10-08 的 32 次共用帳本及其他暫停保留，沒有重設舊預算。
- 參照 [OpenAI 官方模型文件](https://developers.openai.com/api/docs/models/gpt-6.1-sol)。

本輪未接入公開 webhook、持久 Sol 階段、群組設定、語音及引用路由，沒有 LINE 網路發送或 DEV／PRD 部署。未有雙向、期限、重送、未知術語及誤拒正反例的完整證據。字面通過不等於語意通過。

後續應分開評估中越流程接線與未知品項的資訊來源。本句的品項已有人類附圖確認，但本次刻意未提供給模型；自動評審不能保證推得產線原義。若繼續，可使用已確認群組術語，或研究未知標籤保留原文的通用契約；須經正反例驗證，不能採逐句替換或直接發布。
