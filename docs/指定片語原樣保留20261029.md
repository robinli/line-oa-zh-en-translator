# 指定片語原樣保留：mít color

最後更新：2026-10-29；原樣修正 c3 的獨立驗證記錄如下，後續與中越評審整合的發布狀態見 [中越 Sol 整合與 DEV 發布](中越Sol評審與DEV發布20261029.md)。

使用者指定本案例的 `mít color` 不翻譯。這是來源字面保護，不是將它改譯成混色料；先前單句研究的失敗與缺口保持，見 [研究紀錄](中越Sol評審單句研究20261029.md)。

## 保護規則

- 將完整片語列為明確原樣範圍，中越NMT及中英NMT／Sol重譯carrier使用相同辨識器。只保護原文已有內容，不推測替代名稱或人物身分。
- 比對不分大小寫，可包含同一行的多個空白、Tab等水平空白；回覆保留來源的大小寫、字詞及原有空白，不跨換行匹配。
- 以Latin詞界限制完整片語，不擴大至單獨mít、mix color或mít colors／mít colorway。可在中文正文內貼近中文字出現。
- 原生提及維持優先；明確片語與代碼重疊時合併非身分保護範圍，避免重複標記。
- 只有唯一已知id、同來源段落且不屬原生提及的指定片語span，容許供應商改變水平空白。非空白字元須完全相同，然後還原來源完整字串。其他姓名、代碼及原生提及不放寬。
- 改字、缺字、重複、未知id及移段維持拒絕。此保護不判定重量歸屬或其他全文語意正確。
- 出現次數以同一辨識規則逐段核對，計入span外文字、大小寫／水平空白變體、原生提及及合併範圍；兩個carrier共用完整屬性解析器，拒絕重複／衝突或未完整解析的屬性。

## 初次真實觀察與修正

第一筆真實DEV NMT已保留指定字詞，但把來源兩個內部空白縮成一個；當時被既有字面檢查拒絕。原始輸入、回應與失敗均保留，沒有把歷史失敗改標通過。

修正採上述有限水平空白還原，NMT及重譯共用同一判定。持續使用同一回合請求清單，失敗預留保留；增加候選識別不重設10,000碼點累計或根因輪次。
