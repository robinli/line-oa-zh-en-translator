# 群組翻譯啟用功能工作項目

- 文件建立日期：2026-08-12
- 狀態定義：⬜ 未開始／🟡 進行中／⏸️ 阻塞／✅ 已完成
- 需求目標：LINE OA 被加入群組後預設不翻譯；只有指定的單一 LINE 帳號可在群組輸入 `/啟用翻譯`，啟用後持續自動將中文翻譯成英文，直到輸入 `/停用翻譯`。

## 已確認需求

| 項目 | 決定 |
|---|---|
| 授權者 | 只允許指定的一個 LINE 帳號 |
| 啟用方式 | 授權者直接在目標群組輸入 `/啟用翻譯` |
| 有效期 | 啟用狀態持續有效，直到輸入 `/停用翻譯` |
| 狀態範圍 | 以 LINE `groupId` 為單位，各群組獨立啟用或停用 |
| 未啟用行為 | 不呼叫 Google Cloud Translation API，不翻譯普通訊息 |
| 狀態儲存 | 使用 Cloud Firestore 持久化儲存 |
| 授權者設定 | 使用 Firebase Secret `LINE_OWNER_USER_ID`，不寫死在原始碼 |

## 驗收準則

- OA 剛加入群組時，群組預設為未啟用。
- 未啟用時，中文訊息不觸發翻譯 API 或 LINE 翻譯回覆。
- 只有 `LINE_OWNER_USER_ID` 對應的帳號可以啟用或停用群組。
- 非授權帳號輸入啟用或停用指令時，群組狀態不得改變。
- 啟用後，現有中文與中英混合訊息的翻譯功能正常運作。
- 停用後，中文訊息再次停止翻譯。
- Function 重新部署或重啟後，群組啟用狀態仍然保留。
- Secret、授權者 ID 與訊息本文不得出現在原始碼或日誌。
